`models/backends.py` experiment planner, and the EpiBench/R scoring path as
they existed before the 2026-09 unification
([docs/design/restructure-2026-unified.md](../../design/restructure-2026-unified.md)).

they call (`tapestry.models.manager`, `tapestry.model_data.*`,
`tapestry.evaluation.epibench`) no longer exist.

Kept for historical reference (what was run, what the B1 revision/decisive
experiments concluded) — see [docs/workflows/training.md](../../workflows/training.md)
for the current, single workflow.
